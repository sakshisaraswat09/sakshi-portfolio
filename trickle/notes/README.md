# Sakshi Saraswat - Premium Portfolio Website

## Overview
A world-class, premium portfolio website for a Software Engineer at Accenture, designed with modern SaaS aesthetics and recruiter-focused experience. Built with React 18 and premium design principles inspired by Linear, Vercel, Stripe, Raycast, and Apple.

## Key Features
- **Premium Dark Theme**: Sophisticated #050505 background with glassmorphism effects
- **Modern Animations**: Smooth transitions and elegant hover interactions
- **Responsive Design**: Fully responsive across all devices
- **Recruiter-Focused**: Clear hierarchy emphasizing role, skills, and projects
- **Performance Optimized**: Fast loading with optimized assets

## Technology Stack
- **Frontend**: React 18, JavaScript
- **Styling**: TailwindCSS with custom design system
- **Icons**: Lucide Static Icons
- **Animations**: CSS transitions and transforms

## Design System

### Colors
- Primary Background: #050505
- Secondary Background: #0a0a0a
- Accent Primary: #3b82f6 (Blue)
- Accent Secondary: #8b5cf6 (Purple)
- Text Primary: #ffffff
- Text Secondary: #a1a1aa

### Typography
- Font Family: -apple-system, BlinkMacSystemFont, Inter, Segoe UI
- Heading Weight: 600
- Letter Spacing: -0.02em for headings

### Components
- Glassmorphism Cards: rgba(255, 255, 255, 0.03) with blur
- Gradient Text: Linear gradient from blue to purple
- Hover Glow: Box shadow with blue accent
